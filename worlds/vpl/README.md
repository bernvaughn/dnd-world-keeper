# VPL: Vassalboro Public Library

The Vassalboro Public Library game, set in Faerun.

## Setting

Based originally on Forgotten Realms, but it has grown into its own world. Published canon is a starting point only. This repo is the source of truth, and divergences from canon are recorded below.

## Format

This is the library game: 5 to 20 players shuffle between 1 to 3 DMs depending on who can make each session. Everyone plays different quests in the same shared world, so sessions in this repo can involve different parties.
