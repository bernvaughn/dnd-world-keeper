# Neverwinter

City on the coast of Faerun, with a working harbor and a gladiator arena.

## Overview

This version of Neverwinter started as canon Neverwinter from Forgotten Realms. Divergences from canon have not been recorded yet.

**Leadership:** not yet fleshed out.

## Locations

- [Adore Ore](locations/adore-ore.md): blacksmith shop run by Nylit
- [The Akward Canvas](locations/akward-canvas.md): shop run by Leera
- [The Blue Crate](locations/the-blue-crate.md): shop linked to Nimbus
- [The Weeping Dish](locations/the-weeping-dish.md): shop linked to Rurik and Nissa
- [Borquum House](locations/borquum-house.md): home of Ilxaxergesh Borquum
- [Docks](locations/docks.md): harbor, overseen by Harbor Master Karenaise
- [The Old Grape Pharmacy](locations/old-grape-pharmacy.md): pharmacy with a locked back room
- [Freedom Athenaeum](locations/freedom-athenaeum.md): great library turned luxury spa by the djinni Zhudee the Grand
- [Hallowflower Aromatics](locations/hallowflower-aromatics.md): aromatics shop run by Tondin Hallowflower
- [Gravelgaze Shrine](locations/gravelgaze-shrine.md): ruined earth elemental shrine
- [Cinderdeep Forge](locations/cinderdeep-forge.md): ancient dwarven forge inhabited by soot mephits
- [The Driftspire](locations/the-driftspire.md): ruined wizard tower with floating debris
- [Salty Shackle](locations/salty-shackle.md): fisherman bar
- [Blood Orc's Fist](locations/blood-orcs-fist.md): gladiator arena

- [Ilxaxergesh Borquum](../../../../characters/npcs/ilxaxergesh-borquum.md), old dragonborn collector, and his son [Preltann](../../../../characters/npcs/preltann-borquum.md)

- [Tondin Hallowflower](../../../../characters/npcs/tondin-hallowflower.md), alchemist who runs Hallowflower Aromatics

- [Urchin Goldrat](../../../../characters/npcs/urchin-goldrat.md), dwarf fisherman who drinks at the Salty Shackle
