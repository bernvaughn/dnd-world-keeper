# Neverwinter

City on the coast of Faerun, with a working harbor and a gladiator arena.

## Overview

This version of Neverwinter started as canon Neverwinter from Forgotten Realms. Divergences from canon have not been recorded yet.

**Leadership:** not yet fleshed out.

## Locations

- [Adore Ore](locations/adore-ore.md): blacksmith shop run by Nylit
- [The Akward Canvas](locations/akward-canvas.md): shop run by Leera
- [Docks](locations/docks.md): harbor, overseen by Harbor Master Karenaise
- [Blood Orc's Fist](locations/blood-orcs-fist.md): gladiator arena
