# The Creation of the Void

A book. The prized possession of [Zhudee the Grand](../characters/npcs/zhudee-the-grand.md).

## Notes

- It was a trap. [Beram Massan](../characters/npcs/beram-massan.md), a librarian at the [Freedom Athenaeum](../continents/faerun/cities/neverwinter/locations/freedom-athenaeum.md), lost it, which put the library in debt to Zhudee. He claimed the library and turned it into a luxury spa.
- Never found. See [session-2025-09-14-dm1](../sessions/session-2025-09-14-dm1.md).
- What the book contains or does is not recorded.
